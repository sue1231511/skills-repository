## 功能描述
Explainer Studio 是做卡通解说 YouTube 视频的 Claude Code 技能与工具组：选题调研、脚本与事实核查、ElevenLabs 配音与逐词时间戳、手导 HyperFrames 画面、QA 循环、渲染与响度母带，全流程覆盖 10–15 分钟长视频与竖屏 Shorts。

它适合想稳定产出解说视频的频道：从选题到成片，每一步都有对应的技能管着。
