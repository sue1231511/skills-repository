# OneTake ｜ 连续镜头产品宣传片制作

## 仓库
- **feitangyuan/onetake**

## 功能描述
面向 Claude Code / Codex 的产品视频制作 Skill。强调先理解产品与界面，再设计 Beat Sheet、连续镜头、UI 重建、动效、字幕、配音与最终渲染，尽量避免“PPT 一页一页切”的廉价展示感。

### 核心特性
- 以连续镜头与场景变形为核心的产品宣传片工作流
- 支持真实产品 UI / 页面重建与镜头化展示
- 提供 motion 动效能力与镜头衔接思路
- 支持字幕、配音、音效与成片渲染
- 可用于 15–30 秒产品 Launch Film，也可扩展到更长演示
- 强调镜头之间的视觉继承与连续转换，而不是简单淡入淡出

### 适合场景
- 产品宣传片
- SaaS / Web 产品发布视频
- UI / 功能演示视频
- Launch Film
- 需要连续运镜与高级转场的项目展示

## 使用建议
适合负责整片的结构与导演层：先梳理产品卖点和页面，再规划镜头节奏、场景连接与最终成片。若需要更细的具体镜头配方，可与 Video Shotcraft 搭配使用。
