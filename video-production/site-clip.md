# Site Clip ｜ 把网页或 WebGL 场景录成无缝循环视频

## 仓库
- [GitHub: skyeyesec333/site-clip](https://github.com/skyeyesec333/site-clip)（MIT）

## 功能描述
Site Clip 是一个 Claude Code 技能，把网页、滚动故事或 WebGL/three.js 场景录成流畅的无缝循环视频，给作品集或项目页用：shot.json、定住时钟的无头 Chrome、动态模糊、循环、H.264 加 AV1 加 WebP 海报、隐私检查。

录屏软件录的是机器实际跑出来的画面，WebGL 会卡、滚动会抖，而这个技能把页面时钟定住，每帧精确推进 1/60 秒（或 1/120 秒），慢机器也能出完美 60 帧，结尾溶回开头做无缝循环，录制前还会把二维码、邮箱、地址等隐私内容换掉。
