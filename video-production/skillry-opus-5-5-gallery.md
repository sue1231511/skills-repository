# Skillry Opus 5.5 Videos ｜ Opus 5.5 视频创意与 Prompt 案例库

## 官网
- https://skillry.dev/ai-videos/opus-5-5

## 功能描述
Skillry 收集的 Claude Opus 5.5 视频作品案例库。每个案例会展示原始 Prompt，并提供可直接查看的成品/重制效果，适合拿来找视频创意、镜头表现、动效方向和提示词参考。

### 核心特性
- 当前页面收录数会持续增长，截图时约 389 个，现已超过 400 个
- 案例按 Motion graphics、Explainers、3D scenes、Games 等类型分类
- 可查看原始 Prompt 与对应视频结果
- 常见实现涉及 Three.js、Canvas、SVG、HyperFrames 等
- 适合反向研究“Prompt → 成片”的具体关系

### 适合场景
- 给 Claude / Codex / Agent 找视频创意参考
- 抄作业式分析优秀 Prompt 的结构
- 找 Motion Graphics、解释型视频、3D 场景、游戏演示灵感
- 做宣传片、产品演示、短视频时筛选可复用的视觉方向

## 备注
- 这是案例/Prompt 灵感库，不等于单一 Skill
- 页面内容数量会动态变化，仓库里不写死总数
- 与本仓库已有 video-shotcraft、HyperFrames、Remotion 等视频类 Skill 可搭配使用
