# FY Code Animation ｜ 把中文文案变成代码动画成片

## 仓库
- [GitHub: FYZB2020/dsh-fy-code-animation](https://github.com/FYZB2020/dsh-fy-code-animation)（插件代码 MIT；画风库与技能另有来源许可）

## 功能描述
FY Code Animation 是一个 DeepSeek Harness 插件，把中文文案变成成品 MP4，用的不是时间轴、而是代码：Agent 写 HTML/Canvas 动画，再逐帧渲染出来，不用 GPU、不用月费、不用按帧付费，每一帧都是在你自己机器上跑出来的。

它覆盖全文理解与语义分镜、341 个画风的原位检索、气势词与中文动态文字、活的背景与粒子、动作物理、镜头运动、转场接缝、角色表演、像素与卡通与手绘与 3D 分支、图表地图 UI 与图片快闪、四案音乐与音效、Remotion 落地、检查返修与跨 Agent 交接，适用于产品帖、课程预告、数据解说与竖屏短视频。
