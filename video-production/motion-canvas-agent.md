# VideoZero Motion Canvas Skills ｜ Agent 程序化动画视频

## 仓库 / 官网
- [GitHub: VideoZero/skills](https://github.com/VideoZero/skills)

## 功能描述
一套面向 Agent 的 Motion Canvas 视频生成 Skills。通过 TypeScript / JSX 编写结构化动画，并提供编辑器控制、截图、场景树检查和渲染能力。

### 核心特性
- `motion-canvas`：组件、signals、refs、布局、转场、滤镜、渐变、shader 等框架参考
- `motion-canvas-agent`：通过 HTTP API 控制编辑器、seek、截图、场景树与渲染
- `animation-basics`：动画十二原则与 timing 指导
- 适合 Coding Agent 直接生成可编辑动画源码

### 适合场景
- 2D 程序动画
- 信息图动画
- UI / 产品功能演示
- 需要精确时间轴和代码控制的短视频

npx skills add videozero/skills
