# Manim Skill ｜ Agent 自动编写数学动画视频

## 仓库 / 官网
- [GitHub: Yusuke710/manim-skill](https://github.com/Yusuke710/manim-skill)

## 功能描述
让 Claude Code 等 Coding Agent 自动完成 Manim 视频的规划、Python 编码、渲染与迭代，适合制作 3Blue1Brown 风格的程序化动画。

### 核心特性
- Plan → Code → Render → Iterate 工作流
- Agent 自动生成 Manim Python 代码
- 自动运行 Manim 并修正渲染错误
- 支持逐轮反馈修改
- 适合数学、金融、算法和知识解释动画

### 适合场景
- 数学可视化
- 金融与数据概念解释
- 算法与科学原理演示
- 教育视频
