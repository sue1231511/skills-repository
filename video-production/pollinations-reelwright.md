# Pollinations Reelwright ｜ 把一段意图说明变成带旁白、字幕与转场的迷你纪录片，创意步骤经 Pollinations API 完成并用 ffmpeg 校验成片可播放

## 仓库
- [GitHub: SvirepyiBambr/pollinations-reelwright](https://github.com/SvirepyiBambr/pollinations-reelwright)（MIT）

## 功能描述
它把一段意图说明变成带旁白、字幕与转场的迷你纪录片，创意步骤经 Pollinations API 完成并用 ffmpeg 校验成片可播放。
