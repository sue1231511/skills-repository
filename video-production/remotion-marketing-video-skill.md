# Remotion Marketing Video Skill ｜ 高级产品营销视频

## 仓库 / 官网
- [GitHub: xsourabhsharma/remotion-marketing-video-skill](https://github.com/xsourabhsharma/remotion-marketing-video-skill)

## 功能描述
面向 Agent 的 Remotion 营销视频工作流，用 React 与代码动画制作 SaaS Promo、产品 Demo、UI Walkthrough、社交广告、解释视频和 motion graphics。

### 核心特性
- Research / Brief / Asset Inventory
- Scene Planning 与 Design Tokens
- Remotion 确定性动画
- 浏览器 / Remotion Studio 预览
- 修改审批循环
- 字幕、音频、SaaS UI、Cursor 动画参考
- FFmpeg 导出与最终 QA

### 适合场景
- SaaS 宣传片
- APP / Web 产品功能演示
- UI walkthrough
- 社交媒体广告
- 产品发布视频
