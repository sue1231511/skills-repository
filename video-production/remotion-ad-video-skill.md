# Remotion Ad Video Skill ｜ 节拍同步广告视频

## 仓库 / 官网

## 功能描述
Claude Code 视频 Skill，用 Remotion 直接编写产品与 SaaS 广告视频，并结合 Python 做 BPM / Beat Grid 分析、音效合成和视觉 QA。

### 核心特性
- Remotion 代码式广告视频
- 音乐 BPM 与 Beat Grid 检测
- Scene Duration 节拍量化
- SFX 合成与 soundtrack 构建
- Visual QC 循环
- 品牌无关，可套不同产品

### 适合场景
- 产品广告
- SaaS 宣传短片
- 音乐节拍驱动剪辑
- 社交媒体短视频
