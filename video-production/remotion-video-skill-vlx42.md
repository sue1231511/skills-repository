# Remotion Video Skill ｜ 从代码库生成产品宣传视频

## 仓库 / 官网
- [GitHub: vLX42/remotion-video-skill](https://github.com/vLX42/remotion-video-skill)

## 功能描述
面向 Claude Code、GitHub Copilot 等 AI Coding Agent 的 Remotion Skill。读取现有 APP / Web 项目代码，将真实产品 UI 重建为动画场景并输出宣传视频。

### 核心特性
- 读取现有代码库与产品组件
- 自动搭建 Remotion 项目
- 重建真实 UI 为动画镜头
- 转场与特效动画
- 音乐节拍同步
- Preview / Render / Codec 输出指导
- 最终导出 MP4

### 适合场景
- 新功能宣传片
- 产品 Demo Reel
- APP / Web UI 展示
- 从现有代码快速生成发布视频
