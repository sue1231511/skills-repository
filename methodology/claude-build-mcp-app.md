## 功能描述
Anthropic 官方 MCP App Skill。用于在标准 MCP Server 上增加可交互 UI，让工具结果能以内嵌表单、选择器、图表、地图、diff 或实时状态组件显示。

### 核心特性
- MCP Server + UI Resource 的标准结构
- 指导何时该用 Elicitation，何时才值得做 Widget
- 适配 iframe sandbox、hostContext、CSP 与安全区域
- 可构建 Claude 与其他支持 MCP Apps 的宿主可用的交互组件

### 适合场景
- MCP 工具需要复杂表单
- 大列表选择 / 搜索
- 图表、地图、Diff、实时进度 UI
- 需要操作前可视化确认
