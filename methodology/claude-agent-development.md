## 仓库 / 官网
- https://github.com/anthropics/claude-plugins-official/tree/main/plugins/plugin-dev/skills/agent-development

## 功能描述
Anthropic 官方 Subagent 开发 Skill。指导 Agent 文件结构、触发条件、系统提示词、模型选择、工具权限与自主任务边界。

### 核心特性
- 讲清 Agent 与 Command / Skill 的职责区别
- 提供标准 YAML frontmatter 结构
- 强调 description 是自动触发的核心
- 支持模型与工具最小权限配置
- 适合构建 reviewer、tester、researcher 等专用 Agent

### 适合场景
- 拆分复杂任务给并行 Agent
- 编写代码审查 / 测试 / 研究子 Agent
- 给 Claude Code 构建专项角色
