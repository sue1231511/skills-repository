## 功能描述
Repository Deep Analysis Skills 是一套可移植、与环境无关的技能集，让 Agent 像一支专家小队那样对仓库（代码、文档、基建、数据或任意组合）做深度认知分析，定义怎么思考、看什么、如何保持诚实、如何交付，且不依赖任何平台、产品、工具、厂商或环境。

它由总览、方法（0 到 8 阶段）、证据（证据标注、置信度、严重度与诚实规则）、交付物结构、仓库类型适配、专家小队编排，以及每位专家视角的独立技能文档组成，核心原则是理解本身就是工作、证据高于断言、深度高于速度、优点与问题同等认真对待、不知道就说不知道。
