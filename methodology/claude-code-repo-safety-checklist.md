让 Claude Code / Cursor 碰正式仓库前先设好的 5 件事，短小实用：写清仓库规则、拒掉密钥、锁死 MCP、一个 agent 一个 worktree、做完之前必须跑测试。

1. CLAUDE.md or AGENTS.md with repo rules
2. Deny .env and secrets
3. Pin MCP servers. No random installs
4. One Git worktree per agent
5. A test it must run before "done"
