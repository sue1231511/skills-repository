## 功能描述
Harness Core 是一套规则与技能，让 AI 编码 Agent（Claude Code、Codex 等）按一个忙碌的人需要的方式干活：保护注意力、把工作背后的硬约束摆出来、一次只问一个问题、让人始终是交付物的作者。

仓库包含三层核心规则（锁定规则、个人层、默认规则）的 AGENTS.md，可直接装成 Agent 的全局指令，以及 prototype 技能：用一次性的原型回答设计问题（状态模型或逻辑是否合理、界面该长什么样），问题决定原型的形状。
