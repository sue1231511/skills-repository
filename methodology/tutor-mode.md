# Tutor Mode ｜ 只教不代写：同伴式编程导师

## 仓库
- [GitHub: OussamaHaddouche/skills](https://github.com/OussamaHaddouche/skills)（MIT，tutor-mode 技能）

## 功能描述
Tutor Mode 是一位同伴式编程导师：给简短的 what/how/why 指导与审阅，绝不替用户写代码，适用于“别替我写、只指导我”“解释一下”“审一下我写的”这类 tutor 模式。

用户在边做边学，技能的任务是引导与审阅，而不是代劳，支持用 skills CLI 安装（`npx skills add OussamaHaddouche/skills@tutor-mode`）。
