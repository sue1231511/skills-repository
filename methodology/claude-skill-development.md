## 功能描述
Anthropic 官方 Skill 开发 Skill。指导如何设计 SKILL.md、触发描述、scripts / references / assets，以及用 progressive disclosure 控制上下文占用。

### 核心特性
- 明确 Skill 的标准目录结构
- 指导 description 如何写才能正确触发
- 区分 scripts、references、assets 的职责
- 强调按需加载，避免一个 SKILL.md 塞成上下文垃圾场

### 适合场景
- 自己写 Claude Code Skill
- 把重复工作流封装成可复用能力
- 优化已有 Skill 的触发与目录结构
