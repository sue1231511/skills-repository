## 功能描述
Anthropic 官方 Playground Skill。生成单文件交互式 HTML，让用户通过控件实时调整参数、看预览，并自动生成可复制回 Claude 的自然语言 Prompt。

### 核心特性
- 单 HTML 文件，CSS / JS 全内联
- 控件变化立即更新预览
- 自动生成只描述非默认项的自然语言 Prompt
- 内置 design、data explorer、concept map、document critique、diff review、code map 模板思路
- 支持预设组合与复制 Prompt

### 适合场景
- 做设计参数调节器
- 做可视化代码 / diff review 工具
- 复杂 Prompt 的交互式配置器
- 数据与概念探索器
