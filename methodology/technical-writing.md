# Technical Writing ｜ 面向受众写技术文本，不把需求编号漏出去

## 仓库

## 功能描述
Technical Writing 是工程类 Claude Code 插件里的技术写作技能，写、改、审面向不同受众的技术文本：文档注释与 docstring、API 摘要与描述、OpenAPI 或 AsyncAPI 文档、API 报错信息、用户手册、帮助与界面文案、发布说明与更新日志、Runbook 与日志信息、实现注释、README 与设计笔记。

它会在不丢失可追溯性的前提下，把需求、故事或工单编号挡在公开发布的文本之外，适用于任务里出现了 FR-xxx、US-xx、PROJ-123 这类编号、或流程与生命周期需要写清楚的场景。
