# Proof First ｜ 说做完之前先证明它真的能用

## 仓库
- [GitHub: lokki007/proof-first](https://github.com/lokki007/proof-first)（MIT）

## 功能描述
Proof First 要求 AI Agent 在说“做完了”之前先证明它真的能用，因为作者记录了一年与 AI 编码 Agent 的协作，发现约十分之一 Agent 说“做完了”之后，下一条消息就是“还是坏的”，换模型也解决不了这个问题。

做法是按用户的方式检查（看一眼、跑一遍，或坦白说“还没验证”），再以一行 Proof 收尾：`Proof: seen | tested | not yet — 看了或跑了什么`，适用于界面改动、修 bug、部署、数据改动与任何有人会看的东西。
