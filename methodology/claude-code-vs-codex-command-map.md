## 功能描述
换着用两家编程 Agent 的人可以存一下的 Claude Code 与 Codex 命令对照表。

> → CLAUDE.md = AGENTS.md (/init makes either one)
> → /clear = /new
> → /branch = /fork
> → /code-review = /review
> → claude -p = codex exec
> The trap: in Codex, /clear also wipes your terminal. Full table on the card. Save it for the next time you switch.

作者提醒：Codex 里 /clear 还会清掉终端；完整对照表在原帖卡片上。
