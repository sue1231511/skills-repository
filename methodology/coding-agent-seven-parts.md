## 功能描述
这条方法帖把 Claude Code、Codex、Cursor 拆成同一套结构：循环（the loop）、工具（tools）、系统提示词（system prompt）、输出上限（output cap）、压缩（compaction）、沙箱（sandbox）、子代理（subagents），并画了各部分为什么存在，适合理解「为什么你的 Agent 会忘上下文、会乱改文件」。
