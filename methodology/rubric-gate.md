# Rubric Gate ｜ 用真假二值评分卡给 Agent 成果把关

## 仓库
- [GitHub: joshdurum/rubric-gate](https://github.com/joshdurum/rubric-gate)（未声明许可证）

## 功能描述
Rubric Gate 给 AI 编码 Agent 做客观的真假二值质量评分卡与技能有用性自动审计，解决大多数 AI 质量检查要么在“代码干净”“看起来不错”这类模糊愿望后悄悄失败、要么靠 1 到 5 星评分把真问题藏起来的毛病。

它先判断任务复杂度（小修小补直接跳过），再用 rubric.json 里的严格真假标准逐项把关，每条标准直接对应自动化测试，还能审计任何一个 Agent 技能是否过得了客观有用性门槛，适用于 3 个以上文件的新功能、新集成、多会话范围的项目启动时。
