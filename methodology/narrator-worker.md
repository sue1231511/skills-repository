## 功能描述
Narrator Worker 是 DeepSeek Harness 技能仓库里的讲解员加干活双角色协作技能：你（Lead）不亲自执行，而是派一个 worker agent 真正干活，同时向用户持续讲解进度、回答问题、转达需求变更，最后验收并汇报。

它适用于用户要求“一个 agent 干活、一个 AI 在前面解释进度并答疑”、说“讲解模式”“前台模式”“边干边讲”，或长任务需要让用户随时知情的场景。
