# Agent Kit ｜ 按票交付需求，票票过验证与安全审查

## 仓库
- [GitHub: xBajci/agent-kit](https://github.com/xBajci/agent-kit)（MIT）

## 功能描述
Agent Kit 是给 Claude Code 与 Codex 用的插件，增加 Agent、技能与钩子，按票一张一张交付需求，每张票都过验证、安全审查与升级机制。

插件名为 xbajci，通过 agent-kit 市场发布，基于 Matt Pocock 的技能集做了改编：每张票可选用 BDD、一个实现者一张票、各自独立工作区、每张票的验证与安全审查、升级、代码评审与收尾，适用于已经拆好需求、要一张票一张票稳稳交付的场景。
