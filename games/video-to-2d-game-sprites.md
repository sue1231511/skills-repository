# video-to-2d-game-sprites ｜ 把视频转成 2D 游戏透明序列帧

## 仓库 / 官网
- [GitHub: meitianchiMTC/video-to-2d-game-sprites](https://github.com/meitianchiMTC/video-to-2d-game-sprites)（1 Stars，MIT）

## 功能描述
把一段现有视频整理成可直接用于 2D 游戏的透明序列帧：自动镜头稳定与循环接缝修复、主体选择、动作拆分、抠图与固定画布，支持 Cocos Creator 3.8 与 Unity 6 导出。
