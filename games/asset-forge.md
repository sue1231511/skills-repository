# Asset Forge ｜ 在本地 GPU 上免费文生图、文生 3D 游戏资产

## 仓库
- [GitHub: Noamcelermajer/text-to-3d-game-asset-mcp](https://github.com/Noamcelermajer/text-to-3d-game-asset-mcp)（MIT）

## 功能描述
Asset Forge 是本地文生图、文生 3D 游戏资产的 MCP 服务器与 Agent 技能：用自己的 GPU、免费生成概念图、图标、插画与可直接进游戏的 3D 模型（.glb，带烘焙法线贴图与 PBR 贴图），从编码 Agent 或命令行都能用。

它适合独立游戏开发者：不用付费 API，在本地就能把“一段文字描述”变成能直接放进游戏的资产。
