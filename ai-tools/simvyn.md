# simvyn ｜ 一个面板同时管 iOS 模拟器、安卓模拟器和真机，人和 Agent 都能用

## 仓库 / 官网

- [GitHub: pranshuchittora/simvyn](https://github.com/pranshuchittora/simvyn)（约 440 Stars，MIT）

## 功能描述

用一个网页面板或命令行同时操控 iOS 模拟器、安卓模拟器和 USB 连的真机，也能装成 Agent 的 skill 给 AI 用

### 核心特性

- 启动、关闭、管理模拟器和真机；装、启、卸 App
- 看日志并过滤，截图、录屏，开深链接
- 模拟 GPS 定位和路线，切深色模式、语言等设备设置
- 查看 App 的数据库、偏好设置和文件，读写剪贴板，往相册塞图片视频
- 把常用操作存成可复用的合集

### 适用场景

- 手机 App 开发时让 Agent 自己装包、截图、查日志
- 多台设备、多个模拟器来回切的调试

## 安装 / 使用

`npx simvyn` 直接跑，或 `npm install -g simvyn`。需要 Node.js 22.14+ 或 24+。

## 收录笔记

官方写的支持系统：macOS 可管 iOS 和安卓，Linux 只管安卓，**没写支持 Windows**；安卓真机大部分功能能用，iOS 真机只有少数功能。（收录于 2026年11月11日，链接已核验）
