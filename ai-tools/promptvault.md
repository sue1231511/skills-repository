# PromptVault ｜ 自托管的提示词与技能库管理器

## 仓库
- [GitHub: Medenor/PromptVault](https://github.com/Medenor/PromptVault)（MPL-2.0）

## 功能描述
PromptVault 是自托管的提示词与技能库管理器：提示词与技能集中存、集中管，支持筛选、分类、标签、版本管理与导入导出，后端 Python + FastAPI，前端 TypeScript + Vite，可用 Docker 部署。

它适合提示词与技能越攒越多、想有个自己的库来管的人；也可以作为团队内部的提示词资产库。
