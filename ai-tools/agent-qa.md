# agent-qa ｜ 带持久记忆与自我改进的 AI 测试工具

## 仓库 / 官网

- [官网：vostride](https://vostride.com)
- [官方文档](https://vostride.com/docs/agent-qa)

## 功能描述

通过自然语言执行网页、Android 与 iOS 测试，结合 memidex 持久记忆、经验证的自我改进和可复查运行证据。

### 核心特性

- memidex 保存项目事实与可复用流程，将经验证的运行经验和用户反馈整理为可审查的知识。
- 支持 CLI 与本地 MCP 集成，便于编码助手执行测试并检查证据。

### 适用场景

- 网页和移动应用的流程测试、失败排查及测试知识复用。

## 安装 / 使用

按[快速开始](https://vostride.com/docs/agent-qa/quickstart)安装并配置项目、模型和测试目标，要求 Node.js 24+。完成配置后，可通过 `npx agent-qa mcp` 启动[本地 MCP 服务](https://vostride.com/docs/agent-qa/mcp)。

模型及可选设备服务费用取决于配置与用量。运行时许可证为 FSL-1.1-ALv2。
