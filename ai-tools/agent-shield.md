## 功能描述
Agent Shield 像给 AI 插件装的杀毒软件：AI 助手会安装陌生人写的技能、插件（MCP 服务器）与模型文件，坏的会在暗地里让 AI 偷密码、跑有害命令或把文件发出去，而 Agent Shield 在安装之前先读这些文件，告诉你是安全（通过）、值得细看（警告）还是危险（拦截），并指出具体是哪一行。

它覆盖技能、MCP 服务器、Agent 与模型文件的安全扫描，适用于任何要装第三方 Agent 扩展之前先验货的场景。
