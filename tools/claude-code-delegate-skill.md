# Claude Code Delegate Skill ｜ 把活交给子代理去做，只把结果带回来

## 仓库
- [GitHub: FilipMessa/claude-code-delegate-skill](https://github.com/FilipMessa/claude-code-delegate-skill)（MIT）

## 功能描述
Claude Code Delegate Skill 是把任务交给子代理去跑的技能：主会话只当 orchestrator，负责写简报、挑模型与工作量、评判带回来的结果，用户只看到结果。

独立的任务各自派一个子代理并行跑，并行写代码的各用各的工作树，重活（构建、浏览器测试）轮流跑，适合把大任务拆开、又不想被中间过程刷屏时用。
