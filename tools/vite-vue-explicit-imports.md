# Vite Vue Explicit Imports ｜ 把 Vite 和 Vue 项目里的自动导入改成显式导入，让每个符号的来源一目了然，也方便去掉自动导入插件

## 仓库
- [GitHub: hdmy/vite-vue-explicit-imports](https://github.com/hdmy/vite-vue-explicit-imports)（MIT）

## 功能描述
它把 Vite 和 Vue 项目里的自动导入改成显式导入，让每个符号的来源一目了然，也方便去掉自动导入插件。
