# Ship Site ｜ 发到 Cloudflare Pages 并证明它真的上线了

## 仓库
- [GitHub: skyeyesec333/ship-site](https://github.com/skyeyesec333/ship-site)（MIT）

## 功能描述
Ship Site 把静态站或 Vite 应用发到 Cloudflare Pages 并证明它真的上线了，流程是看、提交、推送、构建、wrangler pages deploy、检查线上地址。

它沉淀了一个生产级 three.js 站点几十次发布的教训：一次推送会发布什么、不会发布什么、为什么新密钥“不生效”、25 MiB 文件上限，以及线上函数出问题时怎么看原因，适用于说“发一下”“上线”或改了 Pages 密钥要生效的场景。
