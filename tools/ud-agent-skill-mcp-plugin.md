# UD Agent Skill MCP Plugin ｜ 在 Agent 里校验编辑通用依存树库

## 仓库
- [GitHub: mehmetoguzderin/ud-agent-skill-mcp-plugin](https://github.com/mehmetoguzderin/ud-agent-skill-mcp-plugin)（MIT）

## 功能描述
UD Agent Skill MCP Plugin 在你自己的 Agent 里校验、编辑、比较与研究通用依存（Universal Dependencies）树库与 CoNLL-U 文件，通过 Agent 自带的插件或 MCP 接口安装，打开树库文件夹就能开始工作。

它提供 6 个技能与 104 个应用工具，用上游 UD 工具而不用自己折腾，适用于需要解释依存弧、准备语言规则预览，或处理 CoNLL-U 树图的语言学与 NLP 工作。
