# Extended Resume ｜ 把本地笔记变成带证据的深度简历与面试答案

## 仓库
- [GitHub: Get-Lodely/extended-resume](https://github.com/Get-Lodely/extended-resume)（MIT）

## 功能描述
Extended Resume 是一个 Agent 技能（Claude 与 OpenAI Codex 可用），把电脑上已有的笔记与文档变成有证据支撑的深度职业记录与面试-ready 的行为问题答案，全程不打开用户没批准的文件。

普通简历只留结果、丢掉推理过程，而面试官恰恰追问推理过程：还考虑过什么、会怎么做得不一样、怎么得出结论的。技能从 Documents、桌面、下载、Obsidian、Logseq，以及自愿接入的 Apple Notes、Notion、OneNote、Bear、Joplin 与云盘里取材，记录项目、决策、权衡过的备选、取舍、指标、冲突、失误与反馈，再写出“介绍你自己”“讲一次冲突”“讲一次失败”等高频行为问题的面试答案。
