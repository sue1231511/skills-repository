## 功能描述
GitHub Flow 是 AI SDLC 技能集里的 GitHub Flow 技能，所属仓库把整套 AI 驱动软件开发生命周期（AI SDLC）做成 Claude Code 插件市场，任何仓库用两条命令就能安装，不用再到处复制提示词。

首个插件 git-workflow 包含 GitHub Flow 技能，覆盖从分支、提交到合并的完整流程，适用于想让 Claude Code 按 GitHub Flow 跑开发流程的团队。
