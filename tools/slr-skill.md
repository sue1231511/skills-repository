# Systematic Literature Review ｜ 带人审的系统文献综述技能

## 仓库
- [GitHub: xtobando/slr-skill](https://github.com/xtobando/slr-skill)（MIT）

## 功能描述
Systematic Literature Review 把文献综述从研究问题带到一套可追溯的发现，技能给 Agent 综述指令与一个 Python 工作台，也能用于试点检索或只读一篇 PDF 这类小任务。

综述按流程走：Agent 起草协议与数据库检索式、研究者批准协议、工作台检索数据库与档案并做语义排序、取回 PDF、把图表与公式保留进 Markdown、筛查与提取证据时保留人工审核，最后产出可追溯的综合结论与 PRISMA 导出，适用于学术发现、论文阅读或续跑一次系统文献综述。
