# Biomedical Publication Suite ｜ 把生物医学研究文件夹变成论文

## 仓库
- [GitHub: caude1/biomedical-publication-skill](https://github.com/caude1/biomedical-publication-skill)（MIT）

## 功能描述
Biomedical Publication Suite 是一个生物医学论文写作与发表打磨的 Agent 技能，帮编码 Agent 读一个研究文件夹、理解分析结果、找到最强的科学故事、决定什么该进论文，并起草或修订可投稿的材料。

它是为真实研究项目做的，带图表、表格、模型输出、笔记与半成品，覆盖从研究文件夹到成稿的全过程。
