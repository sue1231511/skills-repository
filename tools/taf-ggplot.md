# TAF ggplot ｜ 把 TAF 工作流里的基础 R 图转成 ggplot2

## 仓库
- [GitHub: ices-taf-dev/ai](https://github.com/ices-taf-dev/ai)（未声明许可证，taf-ggplot 技能）

## 功能描述
TAF ggplot 把 TAF 脚本里的基础 R 图转成 ggplot2 图，或在 TAF 工作流里新建 ggplot2 图，写明哪些文件可以改、utilities.R 主题的用法与视觉风格。

TAF 仓库里的基础绘图代码往往故意写得很简单，转 ggplot2 的目的是在保持代码简单可读的前提下让图更好看，只改绘图代码、不动数据与数值计算，改完要跑完整性校验并看渲染出的 PNG，适用于开发者在 TAF 工作流（data.R、model.R、output.R、report.R）里提到 ggplot 或 ggplot2 的场景。
