## 功能描述
check-github-post-before 是发到 GitHub 之前跑的安全门：检查项目里有没有泄露的密钥、个人数据、疑似恶意代码、隐藏可执行文件与高风险 GitHub Actions，备好清理过的副本，复查通过后才用全新的历史发布。

它分检查员与修复员两个 Agent：先扫、等主人点头、再改副本、再复查，什么都不直接推，适合公开仓库、发代码或上传文件到 GitHub 之前先自查一遍。
