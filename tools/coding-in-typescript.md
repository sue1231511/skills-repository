## 功能描述
Coding in TypeScript 是从 AI Music Video Studio 的编码与 TypeScript 指令里提炼出的通用技能，把跨项目适用的指导抽成独立技能，供任何人写、改、审 TypeScript 代码时使用。

技能覆盖类型与校验器（从所属字段派生类型、在使用点捕获拼写错误、保留可辨识联合类型）、模型与 API 契约、运行时校验、服务、前端代码、测试、重构、注释与 JSDoc，遵循目标项目的框架、工具与既定约定。
