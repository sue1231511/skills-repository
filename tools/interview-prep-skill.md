## 功能描述
interview-prep-skill 是面试准备技能：在 Claude Code 里敲 /interview-prep，它先调研公司、岗位与面试官，再产出一份不超过 3 页 A4 的研究型面试简报（写成 Claude Doc），内容包括“为什么是你、为什么是这家、为什么是这个岗位”的针对性表述。

它适合面试前想快速吃透一家公司、又不想自己通宵做功课的人。
