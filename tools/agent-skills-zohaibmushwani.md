# Agent Skills ｜ 动手前先找开源：oss-first-development 等 5 个技能

## 仓库
- [GitHub: zohaibmushwani/agent-skills](https://github.com/zohaibmushwani/agent-skills)（MIT）

## 功能描述
Agent Skills 是给 Claude Code 与其他支持技能的 Agent 用的 5 个 Agent 技能（SKILL.md 格式），其中 oss-first-development 要求从零写复杂系统之前，先找到、核实并评判已有的开源代码。

它用目标化网络检索（site:、精确短语、文件格式、API 符号）串联标识符，可选长尾 GitHub 主题横扫与用户给定的种子仓库，核查仓库是否含源码、核对许可证（MIT/Apache 与 GPL/AGPL/无许可/非商业的区别），再做复用、改编、借鉴或自写的决定，并给出克隆脚本与构建计划。
