# autarky ｜ 扫出电脑里堆着的 node_modules，挑着删掉腾空间

## 仓库 / 官网

- [GitHub: pranshuchittora/autarky](https://github.com/pranshuchittora/autarky)（约 375 Stars，MIT）

## 功能描述

在终端里扫当前目录下所有子项目的 node_modules，按多久没动过筛选，勾选后确认删除

### 核心特性

- 递归扫描当前目录下的所有 node_modules
- 按"几个月没动"过滤，只删旧项目的
- 自己勾选要删哪些，删前再确认一次

### 适用场景

- 前端项目多、硬盘被 node_modules 吃满的时候

## 安装 / 使用

`npm i -g autarky`，然后在要扫的目录里运行 `autarky`。
