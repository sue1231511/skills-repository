# Claude LLM Council ｜ 向一个 LLM 委员会提问，而不是只问一个模型

## 仓库
- [GitHub: abinashstack/claude-llm-council](https://github.com/abinashstack/claude-llm-council)（MIT）

## 功能描述
Claude LLM Council 是向一个“委员会”提问的 Claude Code 技能：几位成员各自独立回答同一问题，再匿名互评、打分排名，最后由主席综合成一份取众家之长、修正互评挑出的错误的最终答案。

它适合答案质量比速度更重要的问题：让多个视角先吵一架，再交一份更稳的结论。
