# look-before-you-code ｜ 写新模块之前，先找找有没有现成方案

## 仓库
- [GitHub: KemalG-u/look-before-you-code](https://github.com/KemalG-u/look-before-you-code)（Apache-2.0）

## 功能描述
look-before-you-code 是一套“写代码之前先找方案”的技能，外加一个 PreToolUse 门禁钩子：新建约 30 行以上的模块之前，先在本地代码、官方 SDK、包仓库与 GitHub 上并行搜索有没有可维护的现成解法，再决定写不写、怎么写，并留下一张简短的备忘。

装上钩子后，没有新鲜备忘就不让新建文件，适合总忍不住从零造轮子的 Agent 工作流。
