# Agent Display ｜ 给每个 AI agent 分配独立的 macOS 虚拟显示器，让 agent 在自己的屏幕上工作并只截取该屏幕

## 仓库
- [GitHub: 0xzapata/agent-display](https://github.com/0xzapata/agent-display)（MIT）

## 功能描述
它给每个 AI agent 分配独立的 macOS 虚拟显示器，让 agent 在自己的屏幕上工作并只截取该屏幕。
