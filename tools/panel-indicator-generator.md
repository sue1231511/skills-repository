# Panel Indicator Generator ｜ 生成可 3D 打印的背光面板指示灯

## 仓库
- [GitHub: docteurzoidberg/panel-indicator-generator](https://github.com/docteurzoidberg/panel-indicator-generator)（WTFPL v2）

## 功能描述
Panel Indicator Generator 生成可 3D 打印的齐平安装背光指示灯：灯牌亮在面板开孔后的窗口里，像警告灯或仪表盘信号灯，JSON 预设直接转成打印文件。

它提供 CLI、Claude Code 技能与网页版三种用法，适合给任何项目（机箱、控制台、自制设备）做一批带背光图例的指示灯。
