# Hermes Agent Recipes ｜ Hermes Agent 的社区技能与定时任务配方

## 仓库
- [GitHub: marcodallagatta/hermes-agent-recipes](https://github.com/marcodallagatta/hermes-agent-recipes)（MIT）

## 功能描述
Hermes Agent Recipes 是 Hermes Agent 的社区技能与定时任务配方合集：目前含一个可安装技能 tailscale-exit-node-browser-egress（准备一台出口节点设备，让专用浏览器经隔离的回环 SOCKS 代理走该节点上网，并做安全检查与清理），以及 cron 配方与独立指南。

它适合用 Hermes Agent、又想让浏览器流量经指定出口节点走的人；cron 配方是示例，须按自己的配置改过再用。
