# Claude Signal Bench ｜ 分析传感器或 ADC 采样数据，诊断信号采集的问题并推算原因，还能帮硬件开发者算好 STM32 外设参数

## 仓库
- [GitHub: mercan700/claude-signal-bench](https://github.com/mercan700/claude-signal-bench)（MIT）

## 功能描述
它分析传感器或 ADC 采样数据，诊断信号采集的问题并推算原因，还能帮硬件开发者算好 STM32 外设参数。
