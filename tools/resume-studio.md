# Resume Studio ｜ 先建一份主简历，再按每次投递生成页数精准的简历

## 仓库
- [GitHub: AMRUTH-ASHOK/resume-studio](https://github.com/AMRUTH-ASHOK/resume-studio)（MIT）

## 功能描述
Resume Studio 是给 AI 编码 Agent 用的 8 个技能：先把职业经历写进一份主简历作为事实来源，再按每一次投递生成排版精准、无溢出的 LaTeX 简历，附带求职信、预览与审阅流程。

它解决的是“每投一家就得重排一次简历”的麻烦：改主简历一次，各版本自动跟上，适合正在集中投递、每家都要定制简历的人。
