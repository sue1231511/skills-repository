# Labelling Agent Kit ｜ 给内容标注搭一套带证据调优的 Agent 工具包

## 仓库
- [GitHub: llia0031-dotcom/labelling-agent-kit](https://github.com/llia0031-dotcom/labelling-agent-kit)（MIT）

## 功能描述
Labelling Agent Kit 是做内容标注的 Agent 工具包：通过规则与案例文件夹接入任意标注任务，再用预注册的 A/B 实验调优，输出每个标签的精确率、召回率、F1（带区间）、多标签混淆矩阵与切片分析，外加根因分析。

它适合标注质量要拿数字说话的场景：规则是什么、边界在哪、错在哪类样本上，都能查得到。
