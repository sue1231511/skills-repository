# 说说 ｜ 轻博客式碎片笔记系统

## 仓库 / 官网

- [在线站点](https://shuoshuo.zeabur.app/)
- [GitHub: rcy1314/echo-noise](https://github.com/rcy1314/echo-noise)

## 功能描述

一个偏轻博客 / 说说流的个人碎片记录系统，适合发短内容、日常想法、备忘和轻量公开笔记。

### 核心特性

- 轻博客式“说说”信息流
- 支持多栏布局与较高程度的页面自定义
- 适合个人碎片笔记、短内容发布与日常记录
- 项目支持 Docker / Zeabur / Railway / Fly.io 等部署方式
- 可作为 Memos、Flomo 一类轻量记录工具的另一种自托管选择
