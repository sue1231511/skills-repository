# UI Prompt ｜ 70+ 种 UI 风格的提示词模板库，每种风格附完整站点示例

## 仓库 / 官网
- [UI Prompt](https://uiprompt.art/)（另有同一项目的备用域名 [uiprompt.site](https://www.uiprompt.site/zh/home)）

## 功能描述
UI Prompt 是一个 UI 风格提示词模板库，提供 70+ 种 UI 设计风格的完整提示词，每种风格附一个完整站点示例，复制整套提示词即可让 AI 生成对应风格的界面。
