Make it small in scope (like a tiny level) but otherwise impressive fresh graphics. you can pilot the agent cdp browser to create concept art with midjourney and you can use gpt-image-2.6-sunburst high (api key and config in [redacted] and [redacted]) and feed it that midjourney stuff for character sheets you can then use as reference for modeling etc. be creative"
