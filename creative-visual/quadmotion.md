# QuadMotion ｜ 用四分块字符画的终端像素小活物

## 仓库
- [GitHub: LiquidRing/quadmotion](https://github.com/LiquidRing/quadmotion)（MIT）

## 功能描述
QuadMotion 是给终端做的活像素小吉祥物，每一帧都是真实文本：Unicode 四分块字符画出的人物会走路、跳跃、踢球、打喷嚏、雨天打伞、睡觉、打字与绊倒，另附一个 Agent 技能，教你的编码 Agent 自己做这种小活物。

它适用于想在终端里放一个会动的像素小角色，或想让 Agent 学会用四分块字符做无闪烁终端动画的场景。
