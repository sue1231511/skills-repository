# Figure Rig ｜ 让静态 3D 雕塑借骨骼跳起舞来

## 仓库
- [GitHub: skyeyesec333/figure-rig](https://github.com/skyeyesec333/figure-rig)（MIT）

## 功能描述
Figure Rig 是一个 Claude Code 技能，让静态 3D 雕塑动起来：图生 3D 工具（如 Meshy）给你的是一尊雕像——一个融合网格、站在图片里的姿势、常常还带展示底座与贴身道具，而自动绑定工具要的是干净 T 姿势，对它无能为力。

这个技能把雕像按它自己的姿势绑定到一个供体（任意带 Mixamo 骨骼名的已绑定 GLB）上，成品共享供体的骨骼名，供体的跳舞、走路与待机动画可以直接在它身上播放，适用于 three.js 或任意 glTF 播放器。
