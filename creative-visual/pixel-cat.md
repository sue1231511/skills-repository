# Pixel Cat ｜ 把图片、GIF、视频或精灵表转成像素画，可做动画、本地修图或配乐像素短片

## 仓库
- [GitHub: pyros-projects/pixel-cat](https://github.com/pyros-projects/pixel-cat)（MIT（README 自称，无 LICENSE 文件））

## 功能描述
把图片、GIF、视频或精灵表转成像素画，可做动画、本地修图或配乐像素短片。
