# Context Baton ｜ AI 交接棒：tokens 用完前把上下文倒进一个文件

## 仓库
- [GitHub: matheusjean28/brain-dump-template](https://github.com/matheusjean28/brain-dump-template)（MIT）

## 功能描述
Context Baton（context-baton）是一份即插即用的 AI 交接 Markdown 模板：tokens 快用完时，AI 把关于项目的全部上下文（目标、技术栈、决策、已完成、进行中、下一步、已知问题与会话日志）倒进一个文件，下一个 AI 读完就能接着做。

它提供葡萄牙语与英语两版空白模板，适合长任务跨会话不断线，或多个 AI 之间交接项目上下文。
