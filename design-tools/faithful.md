# Faithful ｜ 证明做出来的跟设计稿一致，差在哪一行写清

## 仓库
- [GitHub: appadmin-oss/faithful](https://github.com/appadmin-oss/faithful)（Apache-2.0）

## 功能描述
Faithful 证明做出来的东西跟设计稿一致，面向编码 Agent、设计 Agent 与审阅工作的所有人：设计是一份规格，里面的每个颜色、尺寸、圆角、文案与状态都是定好的，而大多数“跟设计稿对得上吗”的检查，要么是人眯着眼对两张截图，要么是 Agent 说它试过了。

Faithful 把两边都渲染出来、逐个元素配对，用几行 Agent 能直接照着改的话说清到底差在哪：`npx @faithful/cli verify design.html` 即可验证。
