## 仓库 / 官网

## 功能描述
提供大量真实品牌的 design.md / 设计系统参考，让 Agent 按成熟品牌规则做视觉与前端，而不是临场生成一套泛化风格。

### 核心特性
- 多品牌设计系统
- Linear / Stripe / Apple / Spotify 等风格参考
- Design tokens 与组件语言
- 适合 Agent 生成 UI 时建立明确视觉基线
