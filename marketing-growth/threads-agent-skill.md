# Threads Agent Skill ｜ 在 Threads 上发对受众重要、且能被看见的内容

## 仓库
- [GitHub: amelialy/threads-agent-skill](https://github.com/amelialy/threads-agent-skill)（MIT）

## 功能描述
Threads Agent Skill 是 10 个给 Threads 用的 Claude 技能：帮小商家、自由职业者与个人品牌发“对想触达的人重要、且能被看见”的内容，而不是单纯发更多。

它覆盖发帖、回复、倾听、复用、视频与增长打法，适合想让 Threads 真正带来客户、而非只刷存在感的人。
