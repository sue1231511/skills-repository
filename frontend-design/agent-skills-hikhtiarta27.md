# Agent Skills ｜ 把含糊的 UI 反馈改写成精确提示词，还能犀利点评

## 仓库

## 功能描述
Agent Skills 是给不懂设计的普通人准备的两个 Claude Code 技能：design-prompt-rewriter 把“会闪”“感觉很僵”这类含糊的 UI 反馈，用缓动、动量、弹簧、速度等设计原理改写成精确的提示词；ui-roast 则从界面、流程与状态、观感与动效四个角度犀利点评 UI/UX。

它适合不会说设计行话、但想让 Agent 把界面改到位的人。
