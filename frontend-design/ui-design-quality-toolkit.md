# UI Design Quality Toolkit ｜ 设计、规范、实现与验证连起来的前端质量工具包

## 仓库
- [GitHub: pengchengwanli2024/ui-design-quality-toolkit](https://github.com/pengchengwanli2024/ui-design-quality-toolkit)（MIT）

## 功能描述
UI Design Quality Toolkit 把界面设计、项目设计规范、现代 Web 实现与真实验证连接起来，适用于新页面、已有项目 UI 改版，以及需要同时关注交互、兼容性、性能和无障碍的前端优化。

仓库包含按任务范围组合设计、实现与验证流程的 SKILL.md、从参考资料提炼项目规则的 design-md-library、现代浏览器能力与兼容性检索入口 web-quality、项目设计规范最小模板 DESIGN.template.md，以及本地解析 Lighthouse JSON 的报告工具 summarize.py 和回归测试。
