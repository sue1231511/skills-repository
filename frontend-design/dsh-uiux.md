# dsh-uiux ｜ 给 DeepSeek Harness 装设计方向插件

## 仓库
- [GitHub: humphrey-de-conqueror/dsh-uiux](https://github.com/humphrey-de-conqueror/dsh-uiux)（MIT）

## 功能描述
dsh-uiux 是给 DeepSeek Harness 用的设计方向插件：给 Agent 提供具名的视觉风格、每种风格可直接落地的 token 与组件规范、平台搭建规则，以及一道评审标准，用来把住最终成品的质量。

它解决的是 Agent 做界面时风格漂移、没有统一依据的问题，适合在 DeepSeek Harness 里做前端界面时用。
