## 功能描述
一套铅笔手绘风格的 React 组件库：纸张纹理、手写字、笔触线条和淡彩，底下用真正的语义化 HTML 处理输入、选择和键盘交互。

### 核心特性
- 手绘笔迹稳定可复现：同一个绘制种子画出同样的笔触，装饰画布不占布局、不拦截输入
- 颜色、纸张、字体、描边、阴影都由 CSS 设计变量控制，亮色暗色共用同一套组件
- 组件覆盖按钮、表单、导航、卡片表格、弹层、日历、行程地图，后续版本加了依赖图（技能树/科技树）等
- 文档站带中英双语可调参数的 Playground，设计规范按颜色、尺寸间距、字体、图标、材质分页
- 支持 React 18 / 19，带 TypeScript 类型
- MIT（字体等打包资源保留各自许可）

### 适用场景
- 想要手绘、手帐、笔记感界面的 React 项目
- 参考它怎么用设计变量把一整套组件统一起来
- 手绘 SVG 图标与笔触效果的参考

### 安装方式
- `npm install @inkra/react`
- 在入口引入一次 `@inkra/react/styles.css`，样式表里自带默认字体和设计变量
