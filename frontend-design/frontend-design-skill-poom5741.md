# Frontend Design Skill ｜ 去模板味的视觉设计指导

## 仓库
- [GitHub: Poom5741/frontend-design-skill](https://github.com/Poom5741/frontend-design-skill)（Apache-2.0）

## 功能描述
Frontend Design Skill 是给前端视觉设计用的技能：像一家以每位客户都有独特视觉身份著称的设计工作室的设计总监那样做设计，给出审美方向、字体排版与不落模板俗套的选择。

技能包含组件来源的 MIT 白名单机制，只从许可合规的来源取组件，适用于新建界面或重塑已有界面。
