# Rare UI ｜ 少见动效 React 组件（Apple 风）

## 仓库 / 官网
- **swamimalode07/rare-ui**
- https://rareui.com

## 功能描述
主打「少见」动效的 React 组件集合，偏 Apple 风的毛玻璃、弹簧手感，每个组件一个文件，复制进项目后代码归自己。

### 核心特性
- 文件夹动画、流体光球（Fluid Orb）、重力字母（Gravity Letters）、OTP 输入框、时长选择器等
- 基于 Tailwind CSS + Motion
- shadcn CLI 安装：`npx shadcn@latest add swamimalode07/rare-ui/fluid-orb`
- 支持 MCP 安装组件（rareui.com/mcp）

### 许可证（注意）
- **MIT + Commons Clause + 署名要求**（GitHub README 原文，2026-11-02 核对）
- 可用于个人和商业项目，闭源也行；但凡发布的项目用了它的组件，必须在页脚 / 关于页 / 致谢页 / README 之一放一个可见的 rareui.com 链接，源码里的署名和版权声明要保留
- **不许移植到其他框架**，不许单独或打包转售、再分发组件本身
- 所以只能在 React 项目里直接用；Kotlin Compose 等其他框架只能当视觉参考，不能照着源码移植

- AI 产品、Siri 感光效、毛玻璃界面
