# Craftwork Design ｜ 让 Agent 做的界面看起来像设计过的

## 仓库
- [GitHub: craftwork-design/skills](https://github.com/craftwork-design/skills)（MIT）

## 功能描述
Craftwork Design 是一个 Agent 技能，让 Claude Code、Codex、Cursor 等 Agent 搭建的界面看起来像设计过的、而不是生成的，覆盖设计研读（页面类型、设计旋钮、风格家族、典型页面与材料主导型作品的区别）、品味规则（字体、配色、布局、状态、文案、禁用的 AI 味特征），以及从 Craftwork 模板与灵感库取真实参考、按品牌用眼挑字体、锁定一套风格主题并做动效悬停。

技能用 `npx skills add craftwork-design/skills` 安装，适用于任何能读 SKILL.md 的 Agent。
