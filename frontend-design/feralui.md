# FeralUI ｜ 物理感俏皮 React 组件

## 官网
- https://feralui.dev

## 功能描述
小型 React 组件库，做有物理效果、好玩的界面元素，用来给产品加一点俏皮和记忆点。

### 核心特性
- 天花板拉绳开灯，绳子用 Verlet 积分做的真实物理
- 抓娃娃机式验证码
- 小红书帖子另提到会翻页的小书、果冻吉祥物、「App 截图架」，官网正文未核对到

### 适合场景
- 想给页面加一个有记忆点的小交互
