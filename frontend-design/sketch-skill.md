# Sketch Skill ｜ 让 agent 用一支笔的单色草图画出页面布局与交互，避免早期稿件看起来像成品而引来颜色字体方面的反馈

## 仓库
- [GitHub: asabirov/sketch-skill](https://github.com/asabirov/sketch-skill)（Apache-2.0）

## 功能描述
它让 agent 用一支笔的单色草图画出页面布局与交互，避免早期稿件看起来像成品而引来颜色字体方面的反馈。
