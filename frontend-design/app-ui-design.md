## 功能描述
App UI Design 是给编码 Agent 用的界面设计技能：以美学为先，覆盖网站、Web 应用、桌面、移动与终端界面，做设计、打磨与审查。

它适合新建界面、改版现有界面，或对已完成的界面做一次系统的设计审查。
