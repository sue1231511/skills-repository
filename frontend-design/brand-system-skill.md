# Brand System Skill ｜ 像资深品牌设计师一样搭品牌与设计系统

## 仓库
- [GitHub: FrancescoSaverioZuppichini/brand-system-skill](https://github.com/FrancescoSaverioZuppichini/brand-system-skill)（MIT）

## 功能描述
Brand System Skill 让 Agent 像资深品牌与 UX 设计师一样做事：先定品牌策略，再出标志、OKLCH 色彩 token 与一整套可落地的设计系统，并从三个角度给出三条低成本的品牌方向供挑选。

它内置 141 种风格（瑞士、装饰艺术、开发者深色、riso 印刷、巴洛克、Y2K、终端、孟菲斯、轻奢、蒸汽波等），同一张小落地页能按风格逐一渲染对照，适合给新产品定品牌视觉、搭设计系统，或在多个风格方向之间快速比稿。
