# Start UI Design ｜ 参考优先的协作式 UI 设计技能

## 仓库

## 功能描述
Start UI Design 是一套参考优先的协作式 Agent 技能，带设计师与 AI 助手从一份清晰的产品简报出发，经过聚焦提问、视觉与流程调研、组件选择，走到一条可追溯的 UI 设计方向。

它不一上来就出高保真稿，而是先把方向定准，适合新产品的界面设计起步，或在动手之前先把设计依据理清楚。
