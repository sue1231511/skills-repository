# interior.dev ｜ 点击后那半秒的 React 微交互

## 仓库 / 官网
- **ddoemonn/interior**
- https://interior.dev

## 功能描述
免费开源的 React 微交互组件库，专攻「点击后的那半秒」反馈：按钮状态切换不跳、长按确认删除、带档位感的滑块等。口号大意是：软件显得廉价，往往就在点击后的那半秒。

### 核心特性
- 54 个组件，全部 TypeScript，每个组件一个文件
- 示例：Loading Button、Hold to Confirm、Slider Detents、Segmented Control、Like Burst、Copy Button
- 基于 React + Tailwind CSS + Motion
- 直接复制源码，或 shadcn CLI：`npx shadcn@latest add https://www.interior.dev/r/copy-button.json`
- MIT 协议
- 被 21st.dev 评为 Library of the Month

### 适合场景
- 打磨按下态、悬停、加载、确认这类细节，让产品显得「贵」
- MIT 协议，可以照着手感移植到其他框架（如 Kotlin Compose）
