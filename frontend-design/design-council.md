# Design Council ｜ 给前端设计任务配一个混合专家评审团

## 仓库
- [GitHub: shiverin/design-council](https://github.com/shiverin/design-council)（MIT）

## 功能描述
Design Council 是给 Claude Code 用的混合专家路由技能：先给前端设计任务分类，再挑一位主专家与最多两位顾问，写一份共享简报，把审计、方向、构建、专项与评审分给子代理去做，最后裁决专家规则之间的冲突。

它适合较复杂的设计任务：一个人说了不算，让几位“专家”各执一词、再由它拍板。
