# AI Frontend Design Kit ｜ 一次安装，让 Agent 每次改界面都走设计流程

## 仓库
- [GitHub: nuuxcode-arkx/ai-frontend-design-kit](https://github.com/nuuxcode-arkx/ai-frontend-design-kit)（未声明许可证）

## 功能描述
AI Frontend Design Kit 安装一次之后，AI 编码 Agent 每次新建或改动界面都会按一套设计流程走，不用每次再提醒，任务结束还会交一份写明哪些检查做了、哪些没做的回执。

技能把已安装的设计工具按固定顺序串起来（简报、品牌、布局、排版、动效等），适用于 Claude Code 与 Codex，也可用于其他 Agent，覆盖独立 HTML 文件、演示、原型、落地页等所有屏幕工作。
