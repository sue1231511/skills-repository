# Cinematic Scroll Skill ｜ 用 60fps 滚动物理引擎做电影感滚动叙事页

## 仓库
- [GitHub: TuanAnhPhan-pika/cinematic-scroll-skill](https://github.com/TuanAnhPhan-pika/cinematic-scroll-skill)（MIT）

## 功能描述
Cinematic Scroll Skill 用 60fps 滚动耦合的 SVG 物理引擎做连续滚动的交互式网页体验：电影感叙事页、互动漫画与 Apple 风格的滚动页面，滚动与画面严格同步、弹簧物理自然跟手。

它零依赖、纯原生 HTML/CSS/SVG，适合做产品故事页、互动漫画或任何想让滚动本身成为叙事手段的页面。
