# React Native Elements ｜ React Native 的老牌跨平台 UI 组件库

## 仓库 / 官网

- [GitHub: react-native-elements/react-native-elements](https://github.com/react-native-elements/react-native-elements)（约 25.9k Stars，MIT）
- [文档](https://reactnativeelements.com/docs)

## 功能描述

给 React Native 写 App 用的现成界面零件：按钮、卡片、输入框、头像、开关、列表等，一份代码同时用在 iOS 和安卓，也能跑在网页上

### 核心特性

- 跨平台组件，支持 React Native Web
- 有官方 Expo 演示 App，所有组件都能直接看效果
- 带 VS Code 代码片段扩展

### 适用场景

- 用 React Native 快速搭 App 界面

## 安装 / 使用

`npm install @rneui/themed @rneui/base`

## 收录笔记

只适用于 React Native 项目，原生 Kotlin / Swift 的 App 用不上。（收录于 2026年11月11日，链接已核验）
