# Animated SVG Icons ｜ 交互式 SVG 图标

## 仓库 / 官网
- https://github.com/ConvenientSolutions/animated-svg-icons

## 功能描述
专门生成交互式 SVG 图标的 Skill，强调 hover、回弹与状态切换动画，同时避免 layout shift。

### 核心特性
- Framer Motion / requestAnimationFrame
- hover 两阶段动画
- 平滑回位
- 无 layout shift
- 可复用图标组件

## 分类标签
`SVG` `图标` `微交互` `Framer Motion` `前端组件`
